### Correctifs d'audit analyse prédictive : skew guard, baselines, nettoyage (2026-09-22)
- **Skew guard KS réactivé après correction statistique** (`app/infrastructure/ml/skew_guard.py`). Il était désactivé dans `docker-compose.yml` (`ML_SKEW_GUARD_ENABLED:-false`) pour cause de fausses alertes en masse — constat **reproduit** : 47 % de déclenchements sur des données tirées du corpus d'entraînement lui-même. Deux causes, deux correctifs :
  - **A. Unité d'observation = l'enseignant.** Le serving prédit par blocs (toutes les compétences d'un enseignant) et ~15 features sont constantes dans un bloc → pseudo-réplication, le KS comptait n lignes pour une seule observation. `set_reference_from_matrix(M, groups=...)` (le predictor passe `teacher_id`) réduit chaque bloc à sa médiane **des deux côtés**. Sans groupes, le mode ligne historique est conservé.
  - **B. Correction de Holm.** 29 tests simultanés à p<0,01 = ~25 % d'erreur de famille. `p_threshold` est désormais le risque de **famille**, appliqué par Holm (`_holm_rejections`).
  - **Mesuré** : faux positifs 47 % → **0 %** ; détection d'une dérive réelle (+0,5 et +1,0 niveau) **100 %**. **Live vérifié** (image reconstruite, conteneur recréé) : 44 enseignants servis, **37 PRODUCTION_ML / 7 sans features / 0 repli dû au garde-fou**, KS réellement exécuté (`checked=true`, 30 unités, min_p 0,0039 — qui aurait déclenché à tort sous l'ancien seuil brut).
- **Baselines honnêtes** (`pipelines/baselines.py`, nouveau). L'ancienne « persistance » `clip(current_level_t - avg_level, 0, 5)` est **nulle sur 77 % du holdout** (moyenne 0,149 vs cible 2,132) : son RMSE 2,4949 gonflait le lift annoncé d'un facteur ~5. Le contrat expose 4 baselines, écarte les dégénérées et retient la **plus forte** (RMSE la plus basse). Tant que la cible est extrapolée (`is_extrapolated` vrai 217/217), le vrai concurrent est la **règle déterministe à un paramètre** `max(0, requis - clip(niveau_t + (niveau_t-niveau_t3)/3, 1, 5))`, `requis` calibré sur le train seul.
  - **Lift réel de v1.2.0-gb** : **+0,0070, IC95 [-0,1267, +0,1344], NON significatif** (contre 1,2629 « significatif » annoncé). Recalculé par `pipelines/recompute_honest_baselines.py` (idempotent, vérifie le SHA-256 de l'artefact avant écriture, ne touche ni l'artefact ni le `dataset_hash`) → metadata + notes du registre corrigées, ancien chiffre conservé dans `metrics.lift_legacy_persistence_proxy`.
